# Pocket Bullseye release preference

Chris confirmed on 12 September 2026 that the faster release approach should be the default for future Pocket Bullseye work. Read `docs/app-store/RELEASE_POLICY.md` before preparing or submitting a release.

- Preserve existing Apple review submissions and batch routine changes for the next release.
- Keep automatic submission and release after approval configured, with automatic cancellation of previous submissions disabled.
- Prefer independently deployable, compatible backend maintenance where the installed client supports it; do not assume the currently pinned web deployment already supports this.
- Use expedited review only for qualifying critical fixes or associated events, with accurate supporting evidence.
- Apply these defaults without asking Chris to repeat this preference. A later explicit instruction can override the default for a particular release.
