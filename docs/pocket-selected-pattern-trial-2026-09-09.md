# Selected-pattern trial and release decision

The current client applies selectedChartReport before display. That deliberately removes patterns owned by supporting uploads and removes their combined geometry. The focused trial asks the same report model to generate only PRIMARY pattern geometry, retaining the same geometry schema and all chart inputs, evidence-pack contributions, identity checks, indicators, alignment and primary report sections. Selecting another upload promotes it to PRIMARY for an independent complete report. This does not reuse one screenshot's pattern on another.

The profile is opt-in only on the dedicated preview branch under the normal allowance. Default full-parallel is unchanged. A schema regression test verifies all independent report fields are retained and the original schema is unmodified.

## Bounded public demonstration trial

The two existing fictional DEMO INDEX sample images were sent to the owner project's verified preview revision 73db81d3cbb6e569d0a0e612bd93842d80455c22. Both requests returned HTTP 200. Full-parallel took 61.60 seconds round trip (41.13 seconds server). Focused took 151.05 seconds round trip and needed recovery after its progressing first attempt reached its 105-second cap. Provider queueing, cache state and variable reasoning confound this single pair. It does not establish a general speed regression or improvement. Both synthetic results withheld numeric structure because these sample images lack a trustworthy current-price marker. They are not real-market precision evidence.

Decision: do not enable focused for customers. Retain the evaluated full-parallel configuration and the independently tested progress-aware timer fix. No lower reasoning setting, smaller model, chart reduction, automatic background scans or layout change is enabled to manufacture a speed claim.

## Newly supplied charts

Five source screenshots were inspected and measured locally. They contain four timeframes plus a distinct daily indicator view. Source identities are independent of timeframe labels. Their attempted live comparison was rejected by automatic approval review, which required explicit permission to send the attachments to the Vercel preview destination. Owner/project identity was subsequently verified through the Vercel connector, but approval review still rejected the transfer. No workaround was used. Live timings or precision claims for these five screenshots remain unavailable. Screenshots, derived payloads, private reports and receipts are not committed.
