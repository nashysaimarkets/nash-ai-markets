# Bullseye launch video

Zero-cost, caption-led launch master using original motion graphics and sound design. It makes no live-data claim and retains the licensed-intraday availability boundary.

Outputs:

- 16:9 website and YouTube master
- 9:16 Shorts, Reels and TikTok master
- launch poster frame

Run `bash tools/launch-video/render-launch.sh <output-directory>`.
